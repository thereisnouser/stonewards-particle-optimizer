# Changelog

## 0.1.0

- Initial client-side filter for mining hit/break VFX, prop hit VFX and wall destruction VFX.
- Three effect modes: Vanilla, Reduced (25% spawn events), Disabled.
- Discovers VFX IDs from game's ScriptableObjects and loaded props.
- BepInEx configuration and PowerShell build/install script.
- Game actions and Mirror networking logic deliberately unmodified.
